# Seguridad

## Reportar una vulnerabilidad

No publiques credenciales ni detalles explotables en un issue. Usa **Security → Report a vulnerability**. Si todavía no está habilitado, contacta de forma privada al responsable del repositorio.

Incluye componente, impacto, pasos mínimos y una mitigación si la conoces. No incluyas datos financieros o personales reales.

## Principios

- Ningún secreto se almacena en Git.
- El sandbox no recibe dinero ni credenciales financieras reales.
- Las operaciones importantes serán auditables y append-only.
- Las dependencias se actualizan mediante pull requests revisables.
- Los modelos de IA no calculan saldos ni autorizan operaciones.
