# ADR 0001: monolito modular primero

Estado: aceptado.

Se desplegará una API única con límites internos claros. Cuatro personas pueden desarrollar y depurar el sistema sin la carga operativa de microservicios. Un módulo solo se extraerá si necesita escala, seguridad, ritmo de entrega o disponibilidad independientes y las mediciones justifican el costo.
