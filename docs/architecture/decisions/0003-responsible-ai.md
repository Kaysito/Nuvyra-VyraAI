# ADR 0003: IA explicativa, no autoritaria

Estado: aceptado.

Las pérdidas, volatilidad, concentración y señales de conducta se calculan con reglas deterministas y auditables. Un modelo de lenguaje puede convertir esas señales en una explicación adaptada al perfil. No puede inventar precios, alterar el portafolio, impedir una operación ni presentarse como asesor financiero autorizado.
