# ADR 0004: herencia conceptual de KairosAI

Estado: aceptado.

Se preservan el sandbox, el perfil bidimensional, la intervención anti-pánico, la educación contextual y el énfasis en sesgos. No se copia código, configuración, secretos, esquema multi-base ni bloqueo forzoso del proyecto anterior. Toda idea se revalida como requisito de Nuvyra.
