# Constitution de Nuvyra

Estado: vigente.

Estos principios son duraderos y prevalecen sobre decisiones particulares de una feature.

## Principios

1. **User Sovereignty.** Nuvyra nunca toma una decisión financiera por el usuario. El usuario conserva la decisión final.
2. **Explainability.** Toda señal presentada como hecho proviene de datos o cálculos verificables del sistema.
3. **Behavioral Safety.** Nuvyra puede describir patrones observables, pero no diagnostica ansiedad, pánico, miedo, trastornos ni estados médicos o psicológicos.
4. **Domain Integrity.** Las reglas financieras pertenecen al dominio y no se duplican en frontend, API e infraestructura.
5. **AI Boundary.** La IA puede explicar, contextualizar, conversar y transformar información calculada. No es fuente de verdad para balances, posiciones, P/L, precios, scores conductuales, cálculos financieros o perfil de riesgo.
6. **Testability.** Las reglas importantes deben poder verificarse mediante tests.
7. **Privacy.** Solo se recolectan datos necesarios para un propósito explícito.
8. **Zero-Cost November Alpha.** November Alpha debe desarrollarse y demostrarse con `$0 MXN` de infraestructura y servicios obligatorios.
9. **Offline-Capable Demo.** El flujo central de demo debe funcionar localmente sin Internet.
10. **Spec-Anchored Development.** Las funcionalidades significativas deben estar respaldadas por especificaciones y mantenerse sincronizadas con la implementación.
11. **Human in the Loop.** Las decisiones importantes de producto, arquitectura y reglas financieras requieren supervisión humana.
